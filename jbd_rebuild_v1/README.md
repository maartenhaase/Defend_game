# JBD — Bunker Defense rebuild v1

Milestone 1–4 vertical slice focused on Level 1 (Foot Patrol).

- Modular browser source in `src/`
- Build with `node build.js`
- Standalone release in `dist/index.html`
- No external runtime dependencies/assets
- `?debug=1` shows FPS, entity/particle counts, cover nodes and infantry state labels

Controls: tap = MG burst, short hold = AP, long hold = HE. Drag while holding to update aim.
