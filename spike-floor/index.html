Hoi Floor! Kom je spelen?

Het spel kan hier nog niet starten. Je bekijkt waarschijnlijk het HTML-bestand in een voorvertoning van Facebook of je telefoon.

Zo werkt het wel op je iPhone

1. Zet de webapp op een website (bijvoorbeeld GitHub Pages).
2. Open het echte https://-webadres in Safari.
3. Tik op Delen → Zet op beginscherm.

Voor ouders: in een bestandsvoorbeeld worden scripts vaak geblokkeerd. Dit bestand toont daarom uitleg in plaats van een lege achtergrond.
