# SEM in Cantique V11 — iPhone

Een standalone mobiele point-and-click-versie van het fictieve Cantique-spel.
Open vanuit GitHub Pages de map `cantique-adventure/sem-v11/`.
De oorspronkelijke Cantique-adventure in de bovenliggende map is niet aangepast.
De bestanden in data/ vormen samen het mobiele HTML-spel en worden via de loader geladen.
